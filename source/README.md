# 同梱数式レンダラー

`katex.min.cjs` はビルド用のKaTeXです。`scripts/render-content.mjs` がNode.jsから直接呼び出します。ライセンスは [KaTeXのライセンス](../assets/katex-LICENSE.txt) を参照してください。

旧Pythonコードは [制作履歴](../docs/legacy-python/README.md) に移しました。通常の編集・ビルド・検証では使用しません。

`og-image.svg` は共有用画像 `assets/og-image.png`（1200×630）の元図です。IPA Pゴシックで描画してPNGに変換しました。文言を変える場合はSVGを編集し、同じ寸法のPNGに書き出してください。
