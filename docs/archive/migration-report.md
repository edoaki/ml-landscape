## 変更したこと

- 「はじめに → 基礎 → モデル → 分野・タスク → 横断研究」に目次と前後ナビゲーションを変更。モデルの小区分、Transformerの下位に置くViT、横断研究のカテゴリを `navigation.yml` で管理する。
- 58ページIDにページ別Markdownとメタデータを配置。内訳は導入・基本概念を整備した2ページ、既存内容を移行した19ページ、既存内容があり拡充予定の25ページ、本文未公開の12ページ。未執筆ページは「準備中」と予定範囲を表示し、通常の前後ナビゲーションでは飛ばす。
- 本文・見出し・表・TeX・キャプションをMarkdownへ、複雑な図と操作をページ専用部品へ移した。ページ専用JavaScript・CSSをメタデータから読み、本文編集のために共通Pythonやテンプレートを変更する必要をなくした。
- 内部リンクは `page:ID#節`、出典は `source:キー`、専用素材は `media:名前` に統一。保存場所・URL・順序を分離し、旧URL用の案内8ページと、同じURL内で移動した節の案内を生成する。
- 単独ページで使う素材50ファイルをそのページの `media/` に複製。共有・動的参照素材と互換用の元ファイルは保持。出典URLを各ページの `sources.yml` へ分離し、素材の条件・加工・版の記録とキャプションを引き継いだ。
- 旧教材番号と別教材の履修を前提にした案内を修正。導入と基礎に、自分で読める最小限の説明を加えた。新規分野の詳説は追加していない。

編集方法は[README](../../README.md)、ページ単位の保存場所・移行元・実装状態は[移行台帳](migration-inventory.json)と各Markdownの `origins` / `status` / `scope` に記録した。第2節の計画表にも、移行元と今回の状態を追記している。
