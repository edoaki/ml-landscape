# 情報幾何：対象概念を明確にした再構成（2026-09-20）

## 設計

読者の指示により、全折りたたみを撤去。「山」「目盛り」の比喩を外し、図の対象概念と、図から読み取れることを次のように定めた。この設計意図の宣言は教材本文には掲載しない。

| 図 | 対象概念 | 図から読み取ること | 対応を曖昧にしないための条件 |
|---|---|---|---|
| distributions | 統計モデルの空間・統計多様体 | 観測値は一つずつの実現値で、座標空間の一点は出方を定める分布。平均と標準偏差で位置を指定する | 小さな観測点と分布の大きな点を別パネルで描く。A/B/Cを対応させる。 |
| comparison | 統計的な見分けやすさと座標差の区別 | 同じ平均差でも、ばらつきが小さい組は観測値が分かれ、大きい組は重なる | 共通の観測値スケールと同じ平均差。丸と四角で二分布を区別。 |
| metric | Fisher計量と局所近傍 | 同じFisher長の変化に対応する範囲が、分布の位置に応じて変わる | 二パネルの座標尺度・平均方向の矢印は同じ。楕円は各点の計量を固定して計算し、局所近似と明記。 |
| paths | 経路の長さ・測地線・Fisher–Rao距離 | 座標図の直線が、Fisher計量での最短経路とは限らない | 正規分布の正確な測地線を描く。途中の分布も観測値の模式図で示す。 |

本文は、観測値と分布 → 分布の空間 → 見分けやすさ → 計量 → 経路・距離 → KL → 自然勾配の順。通常の本文としてすべて表示する。独立した数式は正規分布のFisher計量の一つに限定し、数値計算は教材本文に置かない。

## 図の条件

観測値の模式図は正規分布の17個の分位点から作成し、実測値や無作為抽出した実験結果とはしない。点の上下のずらしは重なりを避けるためであり、値を表すのは横位置のみ。有限個の観測点が確率分布そのものを定めるように説明しない。分布間のKLやFisher計量も、この点群の見た目の重なりを数えて定義するものとはしない。

楕円は `dμ² + 2dσ² = ε²σ²` に従う各点の計量による範囲。有限距離のFisher–Rao球の厳密な境界ではない。平均方向の同じ矢印は、標準偏差の小さい場所では楕円を出て、大きい場所では中に収まる。

経路図は `(μ,σ)=(-2,1)` から `(2,1)` まで。測地線は `μ² + 2σ² = 6`。標準偏差を固定した経路の長さ4に対し、測地線は約3.24198796。数値積分と閉形式の差は約1.2×10⁻⁸。これらの具体的数値は検証用で、本文には載せない。
