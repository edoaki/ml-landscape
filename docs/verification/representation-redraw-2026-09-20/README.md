# 学習目的の図を描き直し

- 3種の小さな比較カードを撤去し、分類・対照学習・再構成それぞれの本文直下へ独立した横幅800の図を配置。
- 分類：エンコーダ・特徴表現・分類器を分け、正解との比較が中間表現の学習にも使われることを示す。
- 対照学習：CLIPページの特徴空間の見せ方を参考に、MNISTの2つの元画像A/Bと各2種類の見え方、同じ組を近づけ異なる組を離す関係を作図。画像・テキストを対応させるCLIP自体の構造とは区別。
- 再構成：VAEページ内のAE図を基に、エンコーダ→少数の潜在表現→デコーダを描画。右端は復元目標と明記し、VAEの確率分布や生成手順は持ち込まない。
- 追加の7の画像は既に取得したMNIST test index 0（ラベル7）。5は前回と同じtest index 3968。いずれも実データで、対照学習の特徴空間・学習予測は模式例。
- 通常ビルド成功、既存リンク・素材・SVGテスト2件に合格。Chromiumで1440pxと390px、オフライン、390pxのJavaScript無効時を確認。7図の存在、ページ全体の横はみ出しなし、SVG文字のviewBox内配置、ページエラーなし。詳細はchecks.json。
- 大きな図は狭幅時に図の中だけ横スクロール。PC画像を目視し、矢印と注釈の重なりを調整。
