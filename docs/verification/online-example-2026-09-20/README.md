# 継続・オンライン学習の具体例の改稿

継続学習の製品A/Bを四角い金属板／丸い金属部品として説明し、Aも引き続き検査する目的を補った。オンライン学習は、迷惑メールの判定→利用者の訂正→本文と正解による重み更新→次のメールの判定に変更。フォルダ移動と学習を区別し、同じメール例で継続学習との重なりも説明した。

対象ページは通常のMarkdownレンダラーとページテンプレートを用いて個別生成した。全体ビルドは別ページ content/basics/classical/index.md の kernel-map 部品不足で停止。全体ビルド成功とはしていない。

既存の test_landscape.py の2テスト（リンク・素材・アンカー・ID・SVG等）が成功。Chromiumで1440pxと390px、JavaScript無効時の表示を確認し、ページの横はみ出しなし。オンライン学習の図を両幅の画像で目視確認した。

本文だけから、逐次更新の目的・入力・正解・重みの変更・次の予測への引き継ぎ・継続学習との違いを説明できることを制作側で確認した。初学者による試読は未実施。
