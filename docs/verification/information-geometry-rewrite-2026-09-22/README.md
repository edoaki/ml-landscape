# 情報幾何の再構成（2026-09-22）

「分布の集まりに幾何を持ち込む」を主軸に本文を再構成。KLはFisher計量を導く局所的な食い違い、Fisher–Rao距離と自然勾配は計量の二つの使い方として位置づけた。

## 図

- 分布と点：同一スケールの正規分布の密度曲線を、平均・標準偏差の座標に対応させる。
- 座標差と分布の変化：従来の分位点による模式図を使用。
- KL：N(0,1)からN(0,(1+Δσ)²)へのKLを閉形式で計算。Δσの範囲±0.6／±0.06を比較し、局所二次近似Δσ²を重ねる。
- 計量：各点で固定したFisher計量の局所楕円。有限距離の球とは区別。
- 経路：正規分布の測地線と、標準偏差を固定した経路を比較。
- 自然勾配：局所損失の勾配を(−1,−1)とする例。円では方向(1,1)、Fisher計量diag(1,2)では方向(1,1/2)。両図の等高線の傾きと座標尺度は共通。半径は図示用であり矢印長は比較しない。更新ベクトルが楕円境界上で一次近似の損失減少を最大化することを数値確認。
