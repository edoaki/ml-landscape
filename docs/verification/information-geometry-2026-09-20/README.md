## 図の仕様と再現

3組・6パネルの静止図をページ専用HTML部品として同梱。JavaScriptやネット接続なしで表示でき、狭い画面では縦に並ぶ。色に加えて実線・破線・文字で区別する。

1. `distributions.html`：A=(500,1)、B=(502,1)、C=(500,4) の正規分布と、平均・標準偏差の座標での3点。
2. `comparison.html`：平均500→502 mLの変化を標準偏差1 mL、4 mLで比較。両図の軸・目盛りは共通。
3. `paths.html`：(500,1)→(506,1)の水平経路とFisher–Rao測地線、出発・途中・到着の分布。

図は教材用の架空設定に対する独自の計算図。原論文図の転載ではない。

```sh
.venv/bin/python scripts/make_information_geometry_figures.py
.venv/bin/python build.py
```

測地線は `(μ−503)² + 2σ² = 11` の上側の弧。`x=μ/√2, y=σ` と置くとPoincaré上半平面の計量の2倍となり、境界に直交する円弧から得られる。描いた経路の数値積分と、Fisher–Rao距離の閉形式を照合した。実際の充填機を制御する時間や費用を表してはいない。
