# 情報幾何：図を中心にした再改稿（2026-09-20）

読者からの「例が分かりにくく、数値が多い」「基本は図で理解したい」という反応に基づく再改稿。対象は `content/questions/information-geometry/`。充填量の設定を外し、正規分布の山を一貫した例にした。前稿の検証記録は `../information-geometry-2026-09-20/` に残している。

## 本文と図

- 山と点の対応：A・B・Cを分けて描き、同じ文字を分布の座標図に置く。一点が山全体に対応することを明記。
- 中心移動の比較：狭い山と広い山で、移動幅と横・縦の尺度をそろえる。前後は破線・実線でも区別する。
- Fisher計量の目盛り：中心方向の等しいFisher長を、広がりに比例する間隔の目盛りで示す。同じ座標上の移動でまたぐ目盛りが変わる。

図に数値目盛りは置かない。山は正規化した正規分布から生成し、広い山を同じ高さに拡大していない。目盛り図は広がりを固定して中心だけを動かす場合に限定。山の重なり面積がFisher計量そのものではないことも本文で区別した。

主説明に数式はない。3つの数式、経路とFisher–Rao距離、KL、自然勾配は4つの折りたたみ補足に置いた。旧最短経路図を撤去し、生成スクリプトも現在の3組を再生成するものに更新した。

本文から、分布が出やすい値を表すこと、山全体を一点で表せること、狭い山では同じ中心移動でも出方が大きく変わること、その変化に合った物差しがFisher計量であること、学習による分布の更新を考える用途へつながることを短く説明できると確認した。補足の用語を使わず基本説明が成立する。実際の初学者による試読はまだ行っていない。
