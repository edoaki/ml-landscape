# データの設計と品質・評価設計と再現性：図の改訂

対象は `content/questions/datasets` と `content/questions/evaluation`。両ページ専用の図に `assets/data-evaluation-figures.css` を適用。

- データ：従来の抽象的な2図を具体例へ置換し、注釈の形、能動学習の候補選択、誤ラベル修正、条件別の収集件数、不均衡、拡張時のラベル整合の計6図にした。
- 評価：混同行列と指標の分母、検証での設定選択、走行単位の分割、学習の繰り返しによるばらつき、条件別成績の5図を追加。
- すべて独自の模式図・架空の数値例。研究の実測結果として扱っていない。
- 数値照合：全体の正解率94%、再現率80%、適合率約66.7%。3回の平均はモデルA85%、B86%。昼夜を合わせた再現率は93.2%。
- ビルド時のリンク・素材・ID確認成功。既存 `test_landscape.py` の2テスト成功。
- Chromiumをfile URL・オフラインで使用。1280px、390px、390pxでJavaScript無効の3条件で全11図を確認。文書・図の横はみ出し、JavaScriptエラーなし。全図をスクリーンショットで目視確認。
- 図の撮影時のみ固定ヘッダーを非表示にして、図上端への写り込みを回避。
- 制作側で本文と図から、注釈・選択・品質改善の違い、指標の分母、訓練／検証／テストの役割、漏洩、ばらつきと条件別評価を短く説明できるか確認。初学者の試読は未実施。
