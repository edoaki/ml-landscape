## MNIST実験

- CVDFのMNISTミラーを使用。訓練集合から15,000枚を無作為抽出し、784→64（ReLU）→10のMLPを20エポック学習。
- テスト集合から各クラス150枚、合計1,500枚を表示。未学習時と学習後の中間表現を個別にt-SNEで2次元化。図の色付け以外に、t-SNEはラベルを使用しない。
- 全テスト10,000枚の分類正解率：95.01%。これは教材用の単一実験で、手法比較や最良性能の主張には使わない。
- 取得ファイルのSHA256、抽出インデックス、図の座標、ライブラリ版はページの`media/mnist-experiment.json`に保存。
- 図の再生成：NumPy 2.5.3、scikit-learn 1.9.1、Pillowを用意して、リポジトリ直下から`OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 python scripts/make_representation_mnist.py`。初回はCVDFからデータを取得する。通常のHTMLビルドは学習や取得を行わない。
- 手描きの点配置や架空の学習結果は使っていない。他4図は学習目的・規則・出力の関係を示す模式図と明記。
