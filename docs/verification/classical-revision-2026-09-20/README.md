## 本文だけを使った説明の試作（制作側の確認）

- 線形回帰：気温と休日の寄与を足して来客数を予測する。過去の実測との差を小さくする重みを学び、新しい日の入力を式に入れる。特徴を増やす場合は過学習を抑える必要がある。
- ロジスティック回帰：混雑という0・1の正解から重みを学び、合計をシグモイドで確率にする。クラスの確率を予測することと、しきい値で判定することは別である。
- 決定木：分けた後の誤差が小さくなる条件を選び、葉の平均を予測にする。26℃の休日は140人という葉に進む。細かすぎる葉は過学習につながる。
- 木の組み合わせ：フォレストは抽出するデータや分岐候補を変えた木の予測を平均する。ブースティングは現在の予測を直す木を順番に足す。新しい日の正解や残差は利用時には不要。
- SVMとカーネル：SVMはマージンと違反の罰則で境界を学ぶ。カーネルは変換先の内積を直接計算する。両端と中央が異なるクラスなら二乗の特徴で分けやすくなる。SVMとカーネルは同じものではない。
- k-means：正解ラベルなしで、近い中心への割り当てと平均への中心更新を繰り返す。中心が動くと4回の人の所属も変わる。グループの意味と数は別に吟味する。
- PCA：平均を引いた点を分散の大きい方向に投影して座標を減らす。残す軸からのずれは復元できない。分散の保持は予測に重要な情報の保持を保証しない。
- 行列分解：利用者と商品の少数の要因を掛けて足して評価を作る。観測済みの評価から要因を共有して学ぶため未観測も推定できるが、未観測を0点とは扱わない。
- テンソル分解：月も加えるCP分解なら、利用者・商品・月の要因の積を足す。月ごとに変わる予測を表せるが、将来の月の要因は自動では分からない。
