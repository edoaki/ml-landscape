# 機械学習の全体像

[index.html](index.html)をブラウザで直接開いてください。本文・数式・静止図はネット接続やJavaScriptなしで読めます。操作部品にはJavaScriptを、外部資料・外部配信動画にはネット接続を使います。

「準備中」は本文未公開、「拡充予定」は既存説明があり追加の予定範囲が残るページです。画像・映像・音声の条件と出典は各ページのキャプション、および[素材の記録](assets/README.md)にあります。

このフォルダは生成済みの閲覧用教材です。編集するときは元プロジェクトの `content/<区分>/<ページID>/index.md` と編集用READMEを使用してください。

HTMLは `basics/`（基礎）、`models/`（モデル）、`fields/`（分野・タスク）、`questions/`（横断研究）に分類しています。各フォルダと素材は配置を保ったまま配布してください。
